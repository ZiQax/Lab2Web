## Langkah-langkah Praktikum

Berikut adalah alur pengerjaan praktikum beserta hasil tangkapan layarnya:

### 1. Membuat Tabel Data Mahasiswa
Langkah pertama adalah membuat file HTML (`.html`) dan menuliskan deklarasi `<!DOCTYPE html>` beserta struktur kerangka dasar HTML seperti tag `<html>`, `<head>`, dan `<body>` serta menambahkan tag untuk pembuatan tabel `<tr>`, `<th>`, `<td>`.

### 3. Membuat Form Registrasi Mahasiswa
Membuat form registrasi mahasiswa sederhana dengan menambahkan tag `<form>`, `<label>`, `<input>`, `<button>`

### 4. Radio Button dan Checkbox
Menambahkan tag radio button pada form mahasiswa dengan menambahkan tag `<input type=checkbox>`, `<input type=radio>`

![Gambar Radio Button & Checkbox](/praktikum-2-html-lanjutan/image/image-4.png)
